Valgfri forbindelse

På iPhone: Scan med den native Scan3D-app og importér dens projektfil her. Den bruger ARKit på en understøttet LiDAR-enhed.

Hvorfor virker LiDAR ikke direkte her?

Safari-websiden har ikke adgang til telefonens ARKit-LiDAR. Den native scanner skal først signeres, installeres og afprøves på din iPhone; den installation er endnu ikke verificeret. Gratis udviklersignering udløber efter syv dage, medmindre den fornyes. Sensoren udløber ikke.

Live RGBD til Chrome på Windows

Kræver Record3D med Wi-Fi-tilkøb, åben på din iPhone, samt Chrome på en anden enhed på samme private Wi-Fi. Køb og installation udføres ikke af appen. Brug ikke Chrome på den samme iPhone under streaming.

Start Start-Chrome-LiDAR.ps1 på Windows. Start Wi-Fi-streaming i Record3D, og skriv appens viste IPv4-adresse. Ingen firewallændring eller upload.

Ikke forbundet. Kameraet åbnes ikke automatisk.

Sensoren bekræftes ikke af Wi-Fi-protokollen. Et udsnit er højst 20.000 kamerarelative punkter, omtrent 0,1–2,8 m fra tabsbehæftet dybdevideo. Ingen samlet objektrekonstruktion, farvet mesh eller kalibreret opmåling. Stopper ved skjult fane.
